# Cara Minta Estimasi Harga Cetak

Untuk mendapat estimasi yang cepat dan jelas, kirim spesifikasi pekerjaan cetak lewat WhatsApp. Semakin lengkap brief, semakin mudah tim mengecek bahan, waktu produksi, dan kebutuhan finishing.

## Data yang perlu dikirim

1. Jenis produk: buku, banner, stiker, merchandise, UV printing, atau produk custom.
2. Ukuran: contoh A4, 60 x 160 cm, 3 x 1 meter, atau ukuran custom.
3. Jumlah: pcs, lembar, eksemplar, atau meter.
4. Bahan: jika belum tahu, tulis kebutuhan pemakaian agar tim bisa menyarankan bahan.
5. Finishing: laminasi, potong bentuk, jilid, emboss, foil, spot UV, atau finishing lain.
6. Deadline: tanggal dibutuhkan atau jadwal event.
7. File desain: PDF, JPG, PNG, AI, atau PSD bila sudah ada.

## Contoh pesan WhatsApp

Halo Anugerah Printer, saya ingin minta quote. Produk: roll up banner. Ukuran: 60 x 160 cm. Jumlah: 2 pcs. Bahan: standar indoor. Deadline: Jumat. File desain sudah ada dan akan saya kirim setelah chat ini.
